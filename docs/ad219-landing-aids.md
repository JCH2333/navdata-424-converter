# AD 2.19 着陆设施证据

2608 根目录没有独立 ILS CSV。每个机场目录中未被 `Charts.csv` 索引的机场资料 PDF 包含 AD 2.19“无线电导航和着陆设施”页，文本层可直接提供 LOC、GP 和 DME 的来源字段。

当前解析器只接受同一 LOC 记录中明确印刷的项目：跑道、ILS 类别、识别码、MHz 频率、LOC 天线坐标和磁航向；它还会在同页匹配相同跑道和识别码的 GP/DME 坐标、下滑角和 DME 天线标高。每条记录保留机场、PDF 相对路径、页码和 PDF SHA-256。

例如 ZBCF AD 2.19 第 12 页明确给出 `LOC 21 ICF 108.5 MHz N420837.2 E1184955.1`、`212 MAG`、`GP 21` 的 3.2 度下滑角，以及 `DME 21 ICF`。这些内容可由文本层直接重现，不依赖 OCR 或图像模型。

对多个机场与参考库的只读对照已确认：`ILSes.Latitude/Longtitude` 通常对应 LOC 天线坐标，`LocCourse` 对应印刷磁航向，`GsAngle` 对应下滑角，`Elevation` 通常对应 DME 天线标高转换为英尺，`CrossingHeight` 通常是 RDH 米值转换为整数英尺。ZBCF 等少数成品行与当前 PDF 不一致，仍作为兼容性异常诊断，不能反向写入来源模型。

写入器只会为当前官方模板中不存在的机场追加字段完整的 ILS，按 `机场/跑道/识别码/频率` 去重；它不会覆盖官方库已有 ILS。参考库的中国 ILS 中，238 条与官方模板完全一致，218 条为新增，其中 203 条属于新增机场，15 条属于已有机场。首版只允许新增机场的 ILS 进入候选；已有机场增量必须等跑道和机场域替换完整后再处理。

抽样 30 个机场时识别到 23 条唯一 ILS 业务键；其中少数页面缺失可明确读取的航向、GP 或 DME 字段。缺失字段保持为 `NULL`，不能通过跑道反算或参考成品补全。后续写库前需对完整 2608 资料建立字段完整度统计，并从多个源支持样本验证每一个 Fenix 字段映射。
